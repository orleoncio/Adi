<h1>Projeto Adi</h1>

<p>
  O projeto Adi se trata da realização da implementação do algoritmo MinMax para o controle de peças no jogo de tabuleiro indigena chamado Jogo da Onça, para isso foi criado um 
  projeto na unity que visa a implementação da gameplay e do algoritmo usando a linguagem do C#, o intuito desse projeto é encontrar uma forma de adaptação do algoritmo MinMax 
  para jogos de tabuleiro não tão conhecidos pelo grande publico. 
</p>
